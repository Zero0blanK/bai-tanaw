# @tanaw/web

Assessor UI (Next.js App Router, TypeScript, Tailwind, shadcn/ui, Recharts): login, targets and scope, scans,
imports, findings and verification, AI drafts, evidence, dashboard, report view and PDF export. Port 3000.
Calls the API at `NEXT_PUBLIC_API_URL`. See [docs/architecture.md](../../docs/architecture.md).
